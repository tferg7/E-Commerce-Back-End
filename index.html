REST API · Node.js

E-Commerce Back End

An Express and Sequelize API that manages an online store's products, categories, and tags in MySQL, including the many-to-many link between products and tags.

Endpoints

    
GET/api/categoriesAll categories with their products


GET/api/categories/:idOne category with its products


POST/api/categoriesCreate a category: { "category_name": "Jackets" }


PUT/api/categories/:idRename a category


DELETE/api/categories/:idDelete a category


GET/api/productsAll products with category and tags


GET/api/products/:idOne product with category and tags


POST/api/productsCreate a product, optionally with tagIds


PUT/api/products/:idUpdate a product and replace its tags


DELETE/api/products/:idDelete a product


GET/api/tagsAll tags with their products


GET/api/tags/:idOne tag with its products


POST/api/tagsCreate a tag


PUT/api/tags/:idRename a tag


DELETE/api/tags/:idDelete a tag

  


  

    
Data model

    

      
Four tables: category, product, tag, and product_tag.

      
    
        
  • A category has many products; each product belongs to one category.
    • 
        
  • Products and tags are many-to-many through product_tag.
    • 
        
  • Updating a product with tagIds adds new tag links and removes the ones you left out.
    • 
      

    

  


  

    
Run it locally

    

      
    
        
  1. Install Node.js and MySQL, then cd Develop && npm install.
    2. 
        
  2. Create the database: mysql -u root -p < db/schema.sql
    3. 
        
  3. Copy .env.EXAMPLE to .env and add your MySQL user and password.
    4. 
        
  4. Seed sample data: node seeds/index.js
    5. 
        
  5. Start the API: npm start, then call the endpoints at http://localhost:3001/api with Insomnia, Postman, or curl.
